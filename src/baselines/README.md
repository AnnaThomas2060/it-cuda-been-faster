# Baselines Vertical

Owner: Mohamed Ziyadh Mohamed

## Overview
This module houses hand-crafted reference CUDA C++ kernels serving as performance baselines.

## Responsibilities
- Provide verified implementations for memory-bound operators (vector add, softmax, layernorm).
- Provide verified implementations for compute-bound operators (gemm, fused attention).
- Supply standard performance baselines for computing execution speedup ratios.
